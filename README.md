# Lightcore

Lightcore is an all-in-one Discord.js bot using Components V2 as its primary interactive UI.

## Included systems
- Statbot-style server/user/channel analytics
- Live server counters for members, bots, channels, roles, boosts and voice
- Interactive Components V2 setup/control panels
- Configurable panels and embeds
- Automatic logging
- Anti-nuke with audit-log enforcement, thresholds and whitelist
- Xieron-style category tickets with category-specific staff roles, transcripts and logs
- Appy/Tickety-style applications with configurable forms, reviewer roles and accept/deny workflow
- Moderation, utility, fun, economy, leveling, custom commands, premium, no-prefix and Minecraft monitoring
- SQLite persistence

## Latest source package
The complete generated source is included in `lightcore-v4.2-ultimate.zip`. Extract it, copy `.env.example` to `.env`, install dependencies, deploy commands, then start the bot.

    npm install
    npm run deploy
    npm start

Required environment variables are documented in `.env.example`.
